# Book-Publishing-Data-Analysis
As a contracted data analyst, you’ve been given a dataset of published books and their details for analysis. The data needs to be cleaned and wrangled in order to generate the required and relevant visualizations to help managers make decisions. The managers are not technically savvy, as a result, you’ve been given high-level instructions on what to do with the data.

Before creating visual reports, you must first determine the dimensions (size) of the dataset, in order to get a general idea of the data. The managers have also expressed a desire to use a standard naming convention for all columns (either using underscores or using camel case), and that there shouldn’t be any null values in the data.

One of the most problematic columns is the Year column. While importing the data to Excel, the data capturer mistakenly converted the column to a numeric data type, causing the Year column to show decimal values (such as 1987.0). You need to ensure that the years do not contain those extra characters (i.e. 1987.0 should just be 1987). Some values in the year column are completely wrong (such as 300, or -380.0), which the managers would like to remove altogether from the dataframe.

You’re given further instructions to simplify the rating process, by ensuring that the column containing author ratings is limited to only three values (i.e. all values should be changed to either ‘Beginner’, ‘Intermediate’, or ‘Expert’ accordingly). Similarly, the genre column should only have three possible values (i.e. either ‘Fiction’, ‘Non-Fiction’, or ‘Children’). The managers would like to know the operating costs (gross sales – publisher revenue = operating cost) involved in the publishing of each book, this must be represented in a new column in the dataframe). You also need to compute the average book rating for each publisher, as well as the mean, the median, and standard deviation of gross sales. The managers have no use for the sales rank column, and would like to remove that column. Lastly, one of the managers would like a separate dataframe with the names of the top 10 books with a rating of 4 and above.
